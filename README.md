<tr><td><b>Code Horizon</b><br><sub>AI platform</sub></td>
<td>Flutter Web front end over a Node backend. Multi-model routing across GPT, Claude and DeepSeek with streaming, plus the part most AI products skip: a credit ledger with plan tiers, usage metering, abuse guards and an admin dashboard. Redis caching, GitHub integration for deployment.</td></tr>

<tr><td><b>RFID Pallet</b><br><sub>Warehouse system</sub></td>
<td>No official driver existed for the Zebra RFID SDK, so I <b>wrote a custom bridge against the raw byte-level protocol</b>. Tag, store, search and locate, with inventory count mode, barcode fallback and a CSV-exportable audit log. Built for warehouse Wi-Fi that drops mid-aisle, so it captures offline and reconciles on reconnect. Handed over with a requirement-by-requirement traceability matrix.</td></tr>
